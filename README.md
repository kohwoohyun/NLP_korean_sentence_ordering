# 한국어 문장 순서 예측 (Korean Sentence Ordering)

## 프로젝트 개요

DACON '문맥 기반 문장 순서 예측 AI 경진대회'
(종료된 대회) 를 기반으로 한 NLP 학습 프로젝트입니다.

해당 대회 관련 정보나 데이터는 
[문맥 기반 문장 순서 예측 AI 경진대회](https://dacon.io/competitions/official/236489/overview/description)를 통해 확인할 수 있습니다.

뒤섞인 4개의 한국어 문장을 올바른 순서로
배열하는 AI 알고리즘을 개발했습니다.

단순 성능 극대화보다 다양한 접근법을 비교하고
각 방법의 원리를 분석하는 데 초점을 맞췄습니다.

- 환경: Google Colab Pro (A100) + DGX Spark (128GB)
- 사용 모델: kogpt2, kanana-2.1b, polyglot-3.8b,
             Qwen3-4B, Qwen3-14B
  
## 접근 방식

총 3단계로 실험을 진행했습니다.

### Stage 1 — PPL 기반 베이스라인
파인튜닝 없이 사전학습 모델의 Perplexity를 활용했습니다.
4개 문장의 24가지 순열 중 PPL이 가장 낮은 순서를
정답으로 예측합니다.
각 모델별 PPL 성능을 비교했습니다.

코드는 [Stage1](./Stage1)을 통해 확인할 수 있습니다.

### Stage 2 — PPL 원리 검증 + 데이터 증강
PPL 방식이 실제로 동작하는 이유를 수치로 검증하고
파인튜닝을 위한 증강 데이터를 생성했습니다.

코드는 [Stage2](./Stage2)을 통해 확인할 수 있습니다.

### Stage 3 — QLoRA 파인튜닝
문장 순서 태스크를 직접 학습시키는 방식으로 
Stage 2의 증강된 데이터를 이용하여
Stage 1의 PPL 방식과 성능을 비교했습니다.

코드는 [Stage3](./Stage3)을 통해 확인할 수 있습니다.

## 결과 분석

### 1. 문장 구분방식 검증
같은 모델인 경우 문장의 구분방식이 공백인 경우 성능이 가장 뛰어났습니다.
이후 실험에서도 문장을 공백으로 구분해 실험을 진행했습니다.

### 2. 모델 크기보다 사전학습 품질이 중요
kanana-nano (2.1B, 2025년) 가
Qwen3-14B (14B, 글로벌) 를 PPL 방식에서 앞섰습니다.
한국어 특화 최신 모델의 언어 이해 능력이
단순한 파라미터 수보다 중요함을 확인했습니다.

### 3. PPL 원리 직접 검증
Stage2의 실험에서 100개 샘플에서 정답/오답 순서의 PPL을 직접 측정했습니다.

| 구분 | 평균 PPL |
|-----|---------|
| 정답 순서 | 4.02 |
| 틀린 순서 | 4.79 |
| 차이 | 0.77 |

정답 순서가 실제로 PPL이 낮음을 수치로 확인했습니다.

### 4. 파인튜닝 효과는 모델 크기에 비례
| 모델 | PPL 베이스라인 | QLoRA 후 | 향상폭 |
|-----|-------------|---------|------|
| kanana-2.1b | 0.763 | 0.785 | +0.022 |
| Qwen3-14B | 0.660 | 0.855 | +0.195 |

큰 모델일수록 파인튜닝 효과가 크게 나타났습니다.
PPL 베이스라인과 파인튜닝 후 순위가 역전되는
흥미로운 현상을 발견했습니다.

### 5. 파인튜닝 실패 과정 분석
초기 QLoRA 시도에서 성능이 오히려 하락했습니다.
원인 분석 결과 두 가지 문제를 발견했습니다.

첫째, Catastrophic Forgetting으로
파인튜닝이 모델의 일반 언어 능력을 손상시켰습니다.

둘째, 학습/평가 방식 불일치로
프롬프트로 학습하고 PPL로 평가하면
파인튜닝 효과가 제대로 반영되지 않았습니다.

프롬프트 형식 수정과 학습/평가 방식 통일로
해결했습니다.

## 한계 및 개선 방향

### 한계
- 순열 기반 증강으로 데이터 다양성 부족
- QDoRA와 같은 다른 파인튜닝 방식 미적용으로 다양성 부족
- LLM이 아닌 BERT 기법 미적용

### 향후 개선 방향

LLM 기반 데이터 증강 적용해
Qwen3-14B로 원본과 유사한 새로운 문장 생성

QDoRA 적용으로
QLoRA 대비 추가 성능 향상 기대

BERT 기반 접근법 구현으로
LLM vs BERT 성능 비교
