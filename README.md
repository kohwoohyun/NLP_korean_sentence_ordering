# 한국어 문장 순서 예측 (Korean Sentence Ordering)

## 프로젝트 개요

DACON '문맥 기반 문장 순서 예측 AI 경진대회'
(종료된 대회) 를 기반으로 한 NLP 학습 프로젝트입니다.

해당 대회 관련 정보나 데이터는
[문맥 기반 문장 순서 예측 AI 경진대회](https://dacon.io/competitions/official/236489/overview/description)를 통해 확인할 수 있습니다.

뒤섞인 4개의 한국어 문장을 올바른 순서로
배열하는 AI 알고리즘을 개발했습니다.

대회에서 제공한 베이스라인은 T5 모델 기반
Seq2Seq 방식이었습니다.
본 프로젝트에서는 Causal LM의 Perplexity를
활용한 비지도 방식, QLoRA 파인튜닝 방식,
BERT 기반 방식을 직접 구현하고 비교했습니다.

단순 성능 극대화보다 각 방법의 원리를
이해하고 분석하는 데 초점을 맞췄습니다.

- 환경: Google Colab Pro (A100) + DGX Spark (128GB)
- 사용 모델 (LLM): kogpt2, kanana-2.1b, polyglot-3.8b, Qwen3-4B, Qwen3-14B
- 사용 모델 (BERT): klue/roberta-large

---

## 접근 방식

총 4단계로 실험을 진행했습니다.

### Stage 1 — PPL 기반 베이스라인

Perplexity(PPL)는 언어 모델이 텍스트의
자연스러움을 수치로 나타낸 지표입니다.
낮을수록 더 자연스러운 텍스트를 의미합니다.

파인튜닝 없이 사전학습 모델을 그대로 활용해
4개 문장의 24가지 순열 중 PPL이 가장 낮은
순서를 정답으로 예측합니다.
문장 구분방식 3종과 모델 5종을 비교했습니다.

코드는 [Stage1](./Stage1)을 통해 확인할 수 있습니다.

### Stage 2 — PPL 원리 검증 + 데이터 증강

PPL 방식이 실제로 동작하는 이유를
수치로 직접 검증했습니다.
정답 순서와 오답 순서의 PPL을 측정해
정답이 실제로 더 낮은 PPL을 갖는지 확인했습니다.

파인튜닝을 위한 증강 데이터도 생성했습니다.
4개 문장의 24가지 순열을 모두 생성해
원본 7,351개를 176,424개로 확장했습니다.

코드는 [Stage2](./Stage2)을 통해 확인할 수 있습니다.

### Stage 3 — QLoRA 파인튜닝

문장 순서 태스크를 직접 학습시키는 방식으로
Stage 1의 PPL 방식과 성능을 비교했습니다.
4bit 양자화와 LoRA 어댑터를 결합한 QLoRA로
효율적인 파인튜닝을 진행했습니다.

초기 시도의 실패 원인을 분석하고
프롬프트 형식 수정 및 학습/평가 방식 통일로
개선했습니다.

코드는 [Stage3](./Stage3)을 통해 확인할 수 있습니다.

### Stage 4 — BERT 기반 접근법

LLM과 다른 패러다임으로
BERT 계열 모델을 활용했습니다.

klue/roberta-large의 [CLS] 토큰을 활용해
24가지 순열에 점수를 부여하고
가장 높은 점수의 순서를 정답으로 예측합니다.
MarginRankingLoss로 정답 순서가
오답 순서보다 높은 점수를 갖도록 학습했습니다.

코드는 [Stage4](./Stage4)을 통해 확인할 수 있습니다.

## 결과 분석

### 1. 문장 구분방식 비교
공백, 마침표, 줄바꿈 세 가지 방식을
kanana-nano 모델에 적용해 비교했습니다.
공백 방식이 0.763으로 가장 높은 성능을 보였습니다.
이후 모든 실험에서 공백 구분방식을 사용했습니다.

### 2. 모델 크기보다 사전학습 품질이 중요
같은 Qwen3 계열에서 4B(0.455) 대비
14B(0.660)가 0.205 높았습니다.
같은 계열 모델에서는 크기가 클수록 성능이 좋았습니다.

그러나 kanana-nano(2.1B, 0.763)가
Qwen3-14B(14B, 0.660)를 앞섰습니다.
한국어 특화 최신 모델의 언어 이해 능력이
단순한 파라미터 수보다 중요함을 확인했습니다.

### 3. PPL 원리 직접 검증
100개 샘플에서 정답/오답 순서의 PPL을
직접 측정해 방식의 근거를 수치로 확인했습니다.

| 구분 | 평균 PPL |
|-----|---------|
| 정답 순서 | 4.02 |
| 틀린 순서 | 4.79 |
| 차이 | 0.77 |

정답 순서가 실제로 더 낮은 PPL을 가짐을
확인했습니다.

### 4. 파인튜닝 효과는 모델 크기에 비례
큰 모델일수록 파인튜닝 효과가 크게 나타났습니다.
PPL 베이스라인에서 뒤처졌던 Qwen3-14B가
파인튜닝 후 역전되는 현상을 발견했습니다.

| 모델 | PPL | QLoRA 후 | 향상폭 |
|-----|-----|---------|------|
| kanana-2.1b | 0.763 | 0.785 | +0.022 |
| Qwen3-14B | 0.660 | 0.855 | +0.195 |

### 5. 파인튜닝 실패 과정 분석
초기 QLoRA 시도에서 성능이 오히려 하락했습니다.
원인 분석 결과 두 가지 문제를 발견했습니다.

첫째, Catastrophic Forgetting으로
파인튜닝이 모델의 일반 언어 능력을 손상시켰습니다.

둘째, 학습/평가 방식 불일치로
프롬프트로 학습하고 PPL로 평가하면
파인튜닝 효과가 제대로 반영되지 않았습니다.

프롬프트 형식 수정과 학습/평가 방식 통일로
해결했습니다.

### 6. BERT 방식 실패 분석 및 개선
초기 BERT 구현에서 BCEWithLogitsLoss를 사용했으나
정답(4.2%) 대비 오답(95.8%) 의 극심한 불균형으로
모든 순열에 동일한 점수(-3.52)를 출력했습니다.

MarginRankingLoss로 변경해
"정답 점수 > 오답 점수" 를 직접 학습하도록 수정했습니다.
수정 후 0.052에서 0.863으로 크게 향상됐습니다.

### 7. LLM vs BERT 패러다임 비교
LLM PPL 방식은 파인튜닝 없이도
언어 감각으로 자연스러움을 판단합니다.
LLM QLoRA는 태스크를 직접 학습하지만
단방향 문맥 이해의 한계가 있습니다.

BERT 방식은 양방향 문맥 이해로
문장 간 관계 파악에 더 유리하며
MarginRankingLoss로 순서 판단을 직접 학습해
가장 높은 성능을 달성했습니다.

문장 순서 예측 태스크에서는
양방향 문맥 이해가 가능한
BERT 계열이 구조적으로 유리함을 확인했습니다.

## 한계 및 개선 방향

### 한계
- 순열 기반 증강으로 데이터 다양성 부족
  (동일 문장의 순서만 바꾼 것으로 실질적 다양성 없음)
- QDoRA 미적용으로 LLM 방식 추가 개선 미시도
- BERT에서 HNM(Hard Negative Mining) 미적용

### 향후 개선 방향

**LLM 기반 데이터 증강**
LLM으로 원본과 유사한 새로운 문장을 생성해
실질적인 데이터 다양성 확보

**QDoRA 적용**
QLoRA에서 use_dora=True 적용으로
추가 성능 향상 기대

**HNM (Hard Negative Mining) 적용**
BERT 학습 후반부에 모델이 헷갈려하는
어려운 오답 케이스를 집중 학습해
추가 성능 향상 기대
